# Project Overview: Northline Supply

## Purpose
Northline Supply is an embedded Shopify application built to streamline merchant supply workflows, catalog operations, and custom metaobject records directly from the Shopify Admin console.

## Primary Stakeholders
- Merchant Administrators
- Inventory and Supply Managers

## Core Architecture
- Embedded Shopify app utilizing App Bridge React.
- React Router 7 for route management and SSR.
- SQLite + Prisma ORM for session management.
