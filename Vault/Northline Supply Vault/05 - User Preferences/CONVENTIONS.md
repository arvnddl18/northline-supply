# User Preferences & Project Conventions

## Ponytail Execution
- Produce the smallest complete change that solves the problem.
- No speculative abstractions, wrappers, or unused boilerplate.
- Trust existing patterns and platform APIs.
- Summarize changes concisely with what was done and any risks/limits.

## Shopify Development
- Mandatory: Use Shopify AI Toolkit for Shopify API and platform work.
